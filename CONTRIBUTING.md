# Contributing

Thank you for improving this clean-room case study.

1. Create a focused branch from `main`.
2. Use only newly written code and synthetic `DEMO-` fixtures.
3. Never submit production source, customer or employee data, credentials, private URLs,
   screenshots, pricing/licensing rules, or proprietary assets.
4. Run the relevant checks listed in the README.
5. Explain architecture and privacy impact in the pull request.

Changes that blur the public/private boundary will not be accepted. Security findings should follow
[SECURITY.md](SECURITY.md), not a public issue.
